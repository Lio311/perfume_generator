# מחולל תיאורי בשמים - Perfume Generator

אפליקציה מבוססת AI ליצירת תיאורים מקצועיים ויצירתיים לבשמים.

## תכונות

- ✨ יצירת תיאורים מקצועיים באמצעות Google Gemini AI
- 🎨 עיצוב מודרני עם אפקטים של Glassmorphism
- 🌐 תמיכה מלאה בעברית (RTL)
- 💾 שמירת מפתח API באופן מקומי
- 📋 העתקה קלה של התוצאות
- 📱 רספונסיבי לכל המכשירים

## איך להשתמש

1. **קבל מפתח API**:
   - היכנס ל-[Google AI Studio](https://makersuite.google.com/app/apikey)
   - צור מפתח API חינמי
   - העתק את המפתח

2. **מלא את הפרטים**:
   - שם הבושם
   - סוג (נשים/גברים/יוניסקס)
   - תווי ריח עיקריים
   - אירוע/עונה (אופציונלי)
   - מידע נוסף (אופציונלי)

3. **הזן את מפתח ה-API** והקלק על "צור תיאור"

4. **קבל תיאור מקצועי** ומפורט לבושם שלך!

## פריסה ב-Netlify

### אופציה 1: גרירה (Drag & Drop)
1. היכנס ל-[Netlify](https://app.netlify.com/)
2. גרור את התיקייה `perfume-generator` לאזור ה-Drop
3. זהו! האתר שלך חי!

### אופציה 2: Git Integration
1. העלה את התיקייה ל-GitHub repository
2. חבר את ה-repository ל-Netlify
3. פרוס אוטומטית

## טכנולוגיות

- **HTML5** - מבנה סמנטי
- **CSS3** - עיצוב מודרני עם Glassmorphism
- **Vanilla JavaScript** - לוגיקה נקייה ללא תלויות
- **Google Gemini API** - בינה מלאכותית ליצירת תוכן
- **Font Awesome** - אייקונים
- **Google Fonts** - טיפוגרפיה (Heebo, Assistant)
